# نسخه نمایشی آرمان محاسبات قشم

پروتوتایپ سایت آموزشی، اپ موبایل (PWA) و پنل مدیریت. همه داده‌ها نمونه هستند و هیچ اطلاعاتی ذخیره یا ارسال نمی‌شود.

## انتشار روی GitHub Pages

1. در GitHub یک مخزن (Repository) جدید بسازید؛ مثلاً `arman-academy-demo`. در حساب رایگان، مخزن باید **Public** باشد.
2. داخل مخزن: **Add file ← Upload files**. همه **محتوای** این پوشه را بکشید و رها کنید (خود پوشه را نه؛ فایل `index.html` باید در ریشه مخزن باشد). بعد **Commit changes**.
3. بروید به **Settings ← Pages**. در بخش **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** و پوشه **/(root)** ← **Save**
4. بعد از یکی‌دو دقیقه، لینک در همان صفحه نمایش داده می‌شود:
   `https://USERNAME.github.io/arman-academy-demo/`

> فایل `.nojekyll` مخفی است. اگر هنگام آپلود دیده نشد مشکلی نیست؛ سایت بدون آن هم کار می‌کند.

## لینک‌هایی که می‌توانید بفرستید

| بخش | نشانی |
|---|---|
| سایت (صفحه اصلی) | `.../index.html` یا فقط آدرس اصلی |
| اپ موبایل | `.../app-home.html` |
| پنل مدیریت | `.../admin.html` |
| پنل مدیریت در موبایل | `.../app-admin.html` |

در گوشه پایین هر صفحه دکمه **«همه صفحه‌ها»** هست که فهرست کامل صفحه‌ها را باز می‌کند. صفحه‌های اپ روی کامپیوتر داخل قاب گوشی نمایش داده می‌شوند و روی گوشی تمام‌صفحه.

## نصب اپ روی گوشی (PWA)

- **اندروید (Chrome):** لینک `app-home.html` را باز کنید و در بنر بالای صفحه «نصب» را بزنید، یا از منوی مرورگر «Install app / Add to Home screen».
- **آیفون (Safari):** دکمه اشتراک‌گذاری ← **Add to Home Screen**.

بعد از اولین بازدید، اپ بدون اینترنت هم باز می‌شود.

## نکته‌ها

- این نسخه برای موتورهای جستجو بسته شده است (`noindex`).
- فونت وزیرمتن داخل پروژه است و به سرویس خارجی وابسته نیست (مجوز OFL در `assets/fonts`).
- دکمه‌هایی که در نسخه نهایی به سرور وصل می‌شوند (ذخیره، دانلود، پخش ویدیو و…) فقط یک پیام کوتاه نشان می‌دهند.
- برای پنهان کردن دکمه «همه صفحه‌ها» در یک صفحه، به تگ `<body>` آن صفحه `data-proto-nav="off"` اضافه کنید.

## ساختار فایل‌ها

```
index.html, course.html, …        صفحه‌های سایت
app-*.html                        صفحه‌های اپ موبایل
admin-*.html                      پنل مدیریت وب
assets/dc-lite.js                 موتور سبک صفحه‌ها (وضعیت، فیلترها، تب‌ها)
assets/proto.css                  قاب گوشی، فهرست صفحه‌ها، پیام‌ها
manifest.webmanifest, sw.js       تنظیمات PWA و حالت آفلاین
```
